# Public assets

Add portfolio images, videos, and other static assets in this folder.

Suggested structure:

- `images/` — profile photos, project screenshots, thumbnails
- `videos/` — portfolio videos and motion previews
- `documents/` — downloadable CV or portfolio documents

Reference files in your website using paths from the project root, for example:

```html
<img src="/images/kazeem-profile.jpg" alt="Kazeem">
<video controls src="/videos/project-preview.mp4"></video>
```

Keep filenames lowercase and use hyphens instead of spaces.
